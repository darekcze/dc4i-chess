# Szachy DC4I Beta 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax and TDD.

**Goal:** Release a visually distinctive Szachy Beta 3 with system PGN sharing, reliable review explanations, and custom branding.

**Architecture:** Three isolated worktrees built from main. Native Android Intent bridge passes bounded PGN to existing React importer; review explanations display verified Stockfish results; shared CSS tokens/React components and SVG-to-PNG pipeline style the app. Merge only after independent test gates.

**Tech Stack:** React 19, TypeScript, Vitest, Playwright, Capacitor 8, Java Android, Gradle, Stockfish 19.
**Spec:** docs/superpowers/specs/2026-11-11-szachy-v3-design.md

## Global Constraints
- Package com.dc4i.szachy, APK test release Beta 3, keep GPL 3+, upstream credits, no ads/paywall.
- Never provide engine help for live Chess.com play.
- Keep tests/assets reproducible with no user credentials.
- Source scopes separated to avoid conflicts.

## Review Focus
- Cold start share before React listener mounts: buffered text survives navigation.
- Invalid URI or excessive/binary payload: reject safely with user-facing reason.
- Repeated share event or repeated import: no duplicate games/lost input.
- Stored review without PV or best move: no fabricated tactic, no crash.
- Light theme/high contrast and small phone: no unreadable text, clipped nav, icon crop.
